# 静谧自然 · Quiet Nature

一款让人静下来的**真实自然沉浸网页**。与"海滩 3D"项目是**不同主题、不同链接**。

本次重做后的核心概念：**「晨雾草甸 · 一日」**——
用同一片真实草甸/森林场景，通过 24 小时光影色调与氛围音的流动，呈现黎明、白昼、黄昏、深夜的连续变化。
不再是 4 个割裂地点的硬切，而是"一个地方在不同时刻"的沉浸体验。

## 前端（网站）
- 单文件 `index.html`：真实视频背景 + 24 小时光影色调覆盖层、Web Audio 分轨氛围音、
  精简自动隐藏 UI、底部 24h 时间轴、移动端 `100dvh` 铺满、刘海安全区、首次触屏解锁声音。
- 点 ⓘ 可见**素材来源与授权**（自我审核）。

## 后端（媒体服务）`server.js`
原生 Node，无第三方依赖，提供：
- `GET /api/scenes` —— 返回素材清单
- `GET /media/*` —— 流式输送视频、图片、音频
- 前端静态页

本地运行：
```
node server.js
# 打开 http://localhost:8787
```

## 部署
`index.html` + `scenes.json` + `media/` 可直接作为静态站点部署；
`server.js` 用于本地带 API 的媒体服务。视频为按需加载，不会一次性下载全部。
